# kitarasenka / cv

Сайт-визитка с моими проектами на русском и английском: **https://kitarasenka.github.io/cv/**
Английская версия: [?lang=en](https://kitarasenka.github.io/cv/?lang=en)

Статика без сборки: HTML, CSS и JS. Публикуется через GitHub Pages из ветки `main`, каждый пуш обновляет сайт примерно за минуту.

## Что где лежит

| Файл | Что внутри |
|---|---|
| [app.js](app.js) | Весь контент: тексты интерфейса (`UI`), продукты (`PRODUCTS`), боты (`BOTS`), инфраструктура (`INFRA`), ссылки на CV (`CV`) |
| [index.html](index.html) | Разметка страницы |
| [styles.css](styles.css) | Стили и анимации, светлая и тёмная тема |
| `assets/photo.jpg` | Фото 720×720. Если файла нет, показываются инициалы |
| `assets/img/` | Скриншоты и иконки проектов |
| `cv/` | PDF с CV. Сейчас одно английское, его отдают обе кнопки |

Язык выбирается так: сначала параметр `?lang=ru` или `?lang=en`, потом сохранённый выбор посетителя, потом язык браузера.

## Как обновить

- **Текст или проект:** поправь [app.js](app.js). У каждого текста должны быть версии `ru` и `en`.
- **Автоматически:** команда `/update-cv` в Claude Code сверит сайт с проектами в `~/projects` и обновит тексты, ссылки и скриншоты.
- **Новое CV:** положи PDF в `cv/` и укажи путь в `CV` в [app.js](app.js). Исходники `.docx` в git не попадают.

## Запуск локально

```bash
python3 -m http.server 8080
```

Затем открой http://localhost:8080
